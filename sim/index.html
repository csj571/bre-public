BRE-1 — Reading the Simulator

The Eight Nodes

  • S1 · Data Stream — emits one observation per tick from the active scenario.
  • S2 · Signal Conditioning — Kalman filter + BOCPD change-point detector. Fires regime flag when P(r=0) > 0.5.
  • S3 · Feature Extractor — assembles μφ, Σφ from S2 outputs.
  • P1 · Prior Registry — versioned, in-memory store of every prior promotion.
  • P2 · Hierarchical Prior — partial-pooling τ for cross-regime sharing.
  • P3 · GP Kernel — kernel library + live hyperparameters with priors.
  • I1 · GP Surrogate — the hero plot: μ(x) ± aleatoric ± epistemic.
  • I2 · Posterior Engine — importance-weighted hyperparameter ensemble. Reports the effective sample size (ESS) and how concentrated the marginal over (ℓ, η, σn) is. No MCMC: the GP posterior is closed-form.
  • I3 · Entropy Estimator — Htotal = Haleatoric + Hepistemic decomposition.
  • I4 · Model Evidence — log p(y | X, θ) plus BMA bar chart over kernels.
  • D1 · Acquisition — EI / UCB / MES / BALD; argmax marks next query.
  • D2 · Policy — act / defer / query strip below the GP plot.
  • D3 · Action Executor — audit log of every decision with the full pre-action belief.
  • D4 · Posterior → Prior — Bayes-factor promotion gate. Writes a new P1 version when it fires.

The Three Demos

  1. Regime change & non-stationarity. Run the default scenario. Watch S2's BOCPD inset; a magenta line drops at x ≈ 2. The epistemic band visibly re-opens — this is BONE-style discount.
  2. Epistemic vs. aleatoric split. In the entropy strip below the main plot, the darker layer is epistemic (shrinks where observations cluster); the lighter layer is aleatoric (the irreducible noise floor — grows with |x|).
  3. Prior registry versioning. Each time D4's gate fires, a new card slides into the registry strip at the bottom with a hyperparameter diff. Every promotion is timestamped and justified.

Reading the Plot

  • Teal = posterior signal. The line is μ(x); the inner band is epistemic; the outer band is aleatoric.
  • Amber = observations with per-point σobs.
  • Magenta = detected regime change / acquisition argmax.
  • Strip below: act / query / defer regions, color alpha modulated by margin.

The variables

Every slider maps to one symbol in the math. The label above each slider is mode-specific (e.g. "Mean-reversion horizon"); here is what each actually controls in the engine.

SymbolSliderWhat it does
ℓlengthscaleDistance over which f(x) stays correlated. Larger ℓ ⇒ smoother fits. Prior ℓ ~ Gamma(2,1).
ηamplitudePrior std-dev of f. η² is the marginal prior variance (kernel value at zero distance). Prior η ~ HalfN(0,1).
σnnoiseObservation-noise std-dev. Sets how far the fit may miss each point. Prior σn ~ HalfN(0,0.5).
τactact thresholdAct only when total entropy Htotal ≤ τact (confident enough to commit).
τdeferdefer thresholdDefer when the aleatoric share Halea/Htotal ≥ τdefer (noise dominates — more data won't help).
EIGminquery thresholdOtherwise query when epistemic entropy Hepi ≥ EIGmin (information is worth gathering).
τpoolpooling τHierarchical partial pooling: 0 = regimes/cohorts siloed, 1 = fully shared.
BFpromotion gatePromote the posterior to a new prior when log BF (epistemic-entropy reduction, in nats) clears log(BF).
